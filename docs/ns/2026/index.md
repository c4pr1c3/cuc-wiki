# 网络安全

## 一、课程基本信息

* 课程编号：2121030192
* 英文名称：Computer Network Security
* 授课对象：网络空间安全专业
* 开课学期：5
* 学分/学时：2.5/64（2022版教学大纲）
* 先修课程：网络空间安全导论、计算机网络、计算机安全与维护、Python编程
* 教学方式：线上课程学习，线下答疑与实验

### 课程简介

本课程是面向 AI 时代的网络安全攻防实战课程。课程以「边学边做、边做边学」为范式，将传统的分章讲授重构为 8 个实战单元（U0-U7），以整学期渐进式演进一个「含 AI 能力的靶场 Web 应用」综合实践项目（里程碑 M0-M7）为学期主线，围绕安全基线、侦察自动化、Web 漏洞攻防、边界防护构建、检测取证欺骗、AI 赋能与对抗、红蓝对抗综合等真实问题展开；AI 双向贯穿全课程——既讲授 AI 赋能安全攻防，也将 AI 系统本身作为安全对象进行攻击与加固，并通过实例讲解知识点，将安全理论、安全技术和安全工具有机结合。

## 二、课程教学目的和要求

随着人工智能技术与网络安全的深度融合，AI 既能秒级写代码、找漏洞、分析日志，其自身也成为新的攻击面，网络与系统安全专门人才的能力要求正在被重新定义。本课程全面系统地介绍网络安全的基本概念、原理和技术，以「能力簇 × 熟练度 × 证据」为度量框架，重在培养威胁建模思维、攻防不对称、最小权限、纵深防御、可观测与可验证的安全、AI 对抗思维等基本思维范式，按照「道（原理）→ 术（方法）→ 器（工具）→ 造器（自制系统）」分层递进；使学生掌握网络安全知识和关键技术，具备驾驭 AI 完成问题拆解、指挥协同、错误否决与结果担责的综合能力，提高安全意识，增强解决互联网和数字传媒等行业中网络安全问题的能力。
